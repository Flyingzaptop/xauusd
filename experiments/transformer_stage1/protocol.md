# Transformer: stage one only — visible-past aggregation

Run only the user's first stage, then stop for manual review. Do not forecast future candles, run later curriculum stages, or add other learning tasks.

Task: from the visible past reconstruct eight consecutive rolling 15-minute OHLC candles covering the last 120 minutes; the last four also describe the last 60 minutes. Minute-by-minute TRAIN origins make these rolling windows, not always UTC quarter-hour candles. Validation/test origins are quarter-hour aligned. The entire target lies inside visible input. Success is representation/optimization evidence, not future predictability evidence.

Use the existing representation family from Flyingzaptop/xauusd at commit 4128bac87029d1be5b73492e1aaa0aeff24ade82, experiments/angular_tcn/run.py: H/O/C/L log-price displacements mapped to (2/pi)*atan(delta/scale). Lags 1,2,3,5,8,13,21,34,55. Scales s0 and exponent H are fitted on January TRAIN only (median absolute Close lag displacement; log-log slope clipped to [0.1,0.9]). M1/M5/H1 lag scale is s0*(minutes_per_bar*lag)^H. This implements the repository reference; it does not silently redefine vectors as centered OHLC levels.

Vector addition is before nonlinear angle encoding. Reconstruct the per-channel path from cumulative raw displacements, then first Open/last Close/max High/min Low give coarse OHLC. Angles themselves are not summed. Use all four output channels; do not force Open=previous Close. A precise analytic oracle must reconstruct the target from M1 input vectors. No price projection/sorting conceals model errors; report invalid-candle fraction.

Inputs: angular vectors and observation fractions only, contexts 360 M1 / 576 M5 / 336 H1 completed bars. Grids include closures, forward-filled from past Close with observed fraction marking absent data. Last 415 M1 minutes must be real consecutive candles. Reserve enough pre-grid support for all lag features. Relative position and timeframe embeddings are learned model parameters; no absolute price, anchor, dollar-volatility feature, future candle or target token is input. External preceding 15-minute candle anchors price decoding after forward, never model computation or teacher forcing.

Splits: TRAIN January 2024 all eligible minute origins (19,396), validation February 1–7 at 15-minute origins (305), test February 15–29 at 15-minute origins (642). January/February data are research-exposed; no untouched-test claim. Past contexts can cross split boundaries as legitimately observed history; target candles stay in their split for these selected origins. Samples overlap and are dependent.

Architecture: Transformer encoder, 4 layers, width96, 4 attention heads, feedforward192, GELU, pre-LayerNorm, dropout25%. Patch sizes2/6/4 for M1/M5/H1, 360 context tokens plus8 learned historical summary queries. Attention is bidirectional over already-observed history; it never sees future or target tokens. Compare static head width219 with hypernetwork head width128. Hypernetwork: query context96→16→768 values, rank4 correction A(c)B(c)/2 to128→64 layer; output4 angles/query. Almost equal capacity; common initial encoder exactly paired per seed. Output .999*tanh(raw), no OHLC sorting.

Four fits: {static,hyper}×seeds{17,29}. Max30 full chronological epochs per fit, min10, early stop after5 epochs without0.2% relative validation dollar-path-MAE improvement. Cosine LR3e-4→3e-5 across cap, AdamW weight_decay1e-4, batch128, grad clip1. The loss is Huber on cumulative decoded displacements normalized by s15, plus0.1 angular MSE. No absolute price is required in this loss. The correct target has exact zero loss and zero output gradient; deviations are penalized. Verify finite gradients through all encoder layers and hypernetwork.

Checkpoint and architecture selection: lowest validation OHLC path MAE in dollars, computed by external decoder. Ensemble the two seeds' angles before decoding; this is an ensemble estimate, not a probabilistic forecast. Save selected family before test evaluation. Baselines: zero displacement (repeat preceding coarse candle), TRAIN mean target vectors, repeat previous coarse displacement, analytic vector oracle. Frozen-generator diagnostic uses mean TRAIN query contexts, retains real classifier input, and is excluded from architecture selection.

Save train-probe and validation curves, best/last model weights, stage-one predictions, input/source hashes, model checks, independent target/aggregation checks, evenly spaced test examples and worst examples. Stop GPU after downloading final archive. A 25-minute worker budget prevents runaway training. No automatic stage transition; stage2 is absent from trainer.
