# Этап 4 — большой Transformer на сырых M1 всех 222 инструментов (Colab A100), 17.10.2026

Закрывает пункт 2 («side по M1 других инструментов»). Код: `experiments/big_transformer/`.

## Постановка
* Вход: последние 240 минутных свечей (return, log(high/low), маска наличия) каждого из 222 инструментов. Масштабы считаются по 2016–2020.
* Модель: временной Transformer внутри каждого инструмента (патчи по 10 минут, общий для всех) → межрыночный Transformer 8 слоёв, d=512, 8 голов, токены = 222 инструмента + CLS. **25.9 млн параметров.**
* Цель: доходность золота (нормированная на σ) на горизонтах 15/30/60/120 минут. Решение после закрытия минуты t, **вход на Open t+2 (задержка 1 минута)**, выход по Open.
* Контроль: та же архитектура, но в межрыночный стек попадает только токен золота (`gold`).
* Walk-forward: тест 2021–22 / 2023–24 / 2025–26, валидация — полгода перед тестом, purge 1 день, ранняя остановка по валидации.
* Железо: A100 40GB, 670 примеров/с у all222 и 7500/с у gold. Израсходовано около 8.4 юнита (64.44 → 56.01).

## Что завершилось
Остановлено по решению пользователя (ожидание ничего бы не изменило). Завершены fold1 all222 и все три gold-only. Fold2 all222 остановлен на 8000-м шаге (валидация ≈ 0), fold3 all222 не запускался.

## Выводы
1. **Корреляции 0.00–0.02 с меняющимся знаком — шум.** Ни одна конфигурация не выходит на уровень, пригодный для торговли.
2. **Все 222 рынка дали хуже, чем только золото** (fold1: −0.010…−0.025 против +0.005…+0.022). Модель переобучилась на шум: ранняя остановка сработала уже на 4000-м шаге из 12000.
3. Торговля по сигналу везде в минусе после издержек. В ряде периодов модель ставит **только на одну сторону** (доля LONG 100% или 0%): она выучила смещение, а не условный сигнал.
4. Это третья независимая методика (деревья LightGBM, ridge walk-forward, большой Transformer) с одним результатом: **направление золота на горизонтах 15–120 минут по M1 других инструментов не предсказывается**. Связь между рынками отрабатывается внутри той же минуты (корреляция на лаге 0 высокая, на лаге 1 ≈ 0).

## Ограничения
Закрыт именно вариант «M1 свечи + направление + горизонты 15–120 мин + издержки $0.25». Не закрыты: сигнал внутри минуты (нужны тики), долгие горизонты (дни), предсказание волатильности, отдельные новостные режимы. Один набор гиперпараметров, одна инициализация; fold2/3 для all222 не доведены до конца, но fold1 и валидация fold2 показывают тот же результат.
