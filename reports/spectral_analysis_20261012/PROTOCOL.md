# Frozen before outcome inspection
All 354340 observed 2021 candles and all 2356 spectral components read. No calendar interpolation. Current feature available only after candle close. Discovery Jan-Jun; validation Jul-Sep; held-out final evaluation Oct-Dec. This is a retrospective chronological holdout within an existing historical dataset, not a future live test.
Horizons 15,60,120 observed bars. Entry next candle Open; exit Close at t+h. Exclude trades crossing any missing calendar minute, and purge labels across split boundaries. Baseline: past momentum, volatility, trailing ranges/position, candle geometry, time-of-day; spectral extension: energy, phase, entropy at all scales. Full-bin marginal screening is recorded separately; all bins considered, train-ranked candidates evaluated subsequently; no selection on final test.
Main hypotheses: spectral energy predicts future activity; phases predict signed direction; high-energy post-shock reaction predicts reversal more than low-energy reaction. Shocks: past five-bar displacement >2.5*past pre-event 60bar volatility*sqrt(5); at least60bars apart. Reaction measured after5 closed bars; future horizon60. Thresholds calibrated Jan-Jun only. Compare return to pre-shock price and direction continuation, including conditional control for shock magnitude, past volatility and already-observed retracement.
Lightweight ridge models; regularization selected only on validation. Nonlinear one-variable threshold/phase rules discovery-ranked and validation-selected. Costs scenarios USD0,.10,.25,.50,1 round trip per ounce, not actual broker estimates; actual bid/ask unavailable. One position at a time, daily cluster bootstrap confidence intervals. No claim of profitability from in-sample fit or overlapping minute-label sample sizes. No images requested.

Before inspecting any outcome: add nonlinear histogram gradient boosting to check phase × energy interactions (60bar horizon only; price baseline vs identical baseline+spectra). Depth/leaves7, learning rate.05, L2=10, min leaf500, max300iterations; select iteration on chronological validation MSE, not random validation. Train only discovery; no holdout retraining. Direction and log realized volatility evaluated. Model complexity fixed in advance. Two models per feature set; no GPU needed.
Nonlinear spectral extension also includes trailing changes over5/30bars in each band energy/entropy; these are known at signal time. These additions were specified before opening result files. First30year rows are excluded from nonlinear fitting to avoid boundary-filled differences. No future feature changes used.

Implementation checks and final qualifications:
- Calendar-gap filtering is used only to describe uninterrupted intraday outcomes. Such filtering is known after the fact and is not an executable entry rule. A separate gap-inclusive evaluation uses exactly the frozen validation-selected signals, next available Open and observed-bar exit, with no future-gap filter.
- Shock detector cooldown is set immediately at shock detection, BEFORE checking future label availability; future gaps cannot change which shock is detected next. This indexing correction was made during technical review and all affected event tables were recomputed. Final event count2283; earlier commentary numbers were preliminary.
- Later descriptive follow-ups (natural retracement categories, clock hours, activity decay, phase random-sign controls) are explicitly explanatory. The fade-after-extension candidate was identified after inspecting subgroup outcomes: it is post-hoc, and2021 must be treated as discovery for that candidate. Its Oct-Dec result is NOT a fresh independent confirmation.
- Feature statistics/models never use future candles. Label validity filters are explicit. Transaction costs are illustrative price-distance costs per ounce; OHLC alone does not reproduce spread/slippage/carry or intrabar order execution.
