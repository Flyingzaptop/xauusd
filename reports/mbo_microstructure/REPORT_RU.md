# MBO (CME GC) и брокер cTrader: стакан, лимитные заявки, lead–lag (17.10.2026)

Код: `experiments/mbo_microstructure/`. Сырые данные (Databento MBO GLBX.MDP3 GC.FUT, L2 cTrader) в Git не входят.

## 1. Восстановление стакана (февраль 2026, GCJ6)
100.5 млн сообщений за 58 с (numba). Проверка: первая сделка каждого пакета проходит по нашей лучшей цене в 94% случаев,
1.6% — внутри спреда (неявная ликвидность), 0.09% — сквозь, остальное — сделки без стороны агрессора. Тесты: `test_book.py`, `test_sim.py`.

## 2. Предсказуемость микроцены (февраль, 14 дней обучения / 10 теста)
Корреляция на 1 с: +0.047 (без задержки) → +0.034 (100 мс) → +0.019 (500 мс) → +0.011 (1 с). Лучший 1% сигналов: +1…3.5 тика,
медианный спред 6 тиков → тейкером не окупается.

## 3. Пассивные заявки (симулятор очереди)
2.2 млн виртуальных 1-лотовых заявок на лучший bid/ask, 5 с жизни: исполнилось 7.7%. В момент исполнения мид на +3.9 тика лучше цены,
через 5 с — 0.0 тика: адверс-селекция съедает полспреда полностью.

## 4. Lead–lag CME → брокер (7–24 июля 2026, реальный счёт, GCQ6 vs XAUUSD)
* Котировки брокера приходят пачками ~раз в 100 мс; спред брокера $0.16, CME $0.40; базис CME−брокер +$11 → +$2.4 (сходимость фьючерса).
* Кросс-корреляция изменений за 500 мс: пик **0.83 при сдвиге брокера +180 мс** (при 0 мс — 0.59). По дням: 130–200 мс, два дня 280/340 мс.
* После скачка CME ≥ $0.5 за 100 мс (11 908 событий): брокер отражает 0% движения через 50 мс, 24% через 100 мс, 67% через 150 мс, 86% через 200 мс.
* Бумажная сделка у брокера (рыночный вход по ask/bid через L мс после скачка CME, выход через 1 с по bid/ask), $/унцию, доля прибыльных:

| L (полная задержка) | $0.3+ | $0.5+ | $1.0+ |
|---|---|---|---|
| 0 мс | +0.22 (81%) | +0.46 (91%) | +1.14 (95%) |
| 50 мс | +0.18 (75%) | +0.40 (85%) | +1.03 (91%) |
| 100 мс | +0.08 (58%) | +0.24 (69%) | +0.72 (77%) |
| 200 мс | −0.10 (28%) | −0.05 (36%) | +0.15 (47%) |

  Каждый из 14 дней в плюсе при L=50 мс (+$0.31…0.45/унцию на сделку). Комиссия брокера не учтена (~$0.07/унцию за круг на raw-счёте).

## Ограничения (решающие)
1. Метки времени L2 — часы машины, которая писала поток (разрешение 100 нс → вероятно Windows). Неизвестны синхронизация и сдвиг часов:
   измеренные 160–180 мс включают этот сдвиг. Нужна проверка на одной машине с синхронизированными часами.
2. L — это **вся** цепочка: доставка данных CME к тебе (из Чикаго в Европу обычно десятки мс) + решение + доставка ордера брокеру + его исполнение.
3. Цена в потоке глубины ≠ гарантированное исполнение: проскальзывание, отказы и requote («last look») не смоделированы.
4. Торговля на запаздывании котировок (latency arbitrage) у большинства CFD-брокеров **запрещена условиями**; сделки могут отменить,
   а счёт закрыть. Это нужно проверить в договоре до любых реальных денег.
5. Только 14 дней июля.

## 5. Следы крупных игроков в MBO (февраль — поиск; март и июль — проверка теми же правилами)
Код: `events.py`, `run_events.py`, `event_returns.py`. События: айсберг (исполнено больше, чем было видно; видно по одному order_id с Modify-доливами),
крупная лимитная заявка ≥5 лотов у лучшей цены (обычная заявка — 1 лот), снятие такой заявки, агрессивный объём ≥10 лотов в одном пакете.
Вход через 300 мс, движение мид-цены CME в сторону события, $/унцию; дубликаты убраны (одно событие на тип/сторону за 10 с); t по минутным кластерам.

| Событие → горизонт | Февраль | Март | Июль |
|---|---|---|---|
| Крупная лимитка ≥10 → 60 с | −0.16 (t −2.0) | −0.01 (t −0.2) | −0.09 (t −3.0) |
| Крупная лимитка (все) → 300 с | −0.21 (t −2.5) | +0.00 | −0.03 |
| Агрессивный удар ≥10 → 60 с | −0.20 (t −4.4) | −0.04 (t −1.1) | −0.02 (t −0.8) |
| Агрессивный удар ≥10 → 300 с | −0.28 (t −2.6) | −0.05 (t −0.6) | −0.09 (t −2.1) |
| Айсберг (все) → 300 с | +0.15 (t +1.8) | −0.03 | −0.15 (t −1.9) |
| Снятие крупной заявки → 1 с | −0.03 (t −2.0) | −0.04 (t −2.5) | +0.00 |

Знак у «крупная лимитка → цена против неё» и «крупный удар → откат» в основном одинаковый во всех трёх месяцах, но величина
$0.02–0.09 вне февраля, а издержки при торговле у брокера ≈ $0.23 за круг. Айсберги меняют знак от месяца к месяцу.
**Вывод: торгуемого edge при задержке 300 мс и издержках брокера нет.** Февраль (аномально волатильный) завышал эффекты.
