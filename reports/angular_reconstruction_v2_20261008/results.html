Восстановление: способность сети, loss и интерполяция

Вариант C обошёл обычную линейную интерполяцию, но преимущество над мостом с правым Open не подтверждено.

Диагностика

Та же сеть на восьми известных TRAIN-окнах с обычным угловым MSE достигла RMSE угла 0.0663°, MAE цены 0.03919 bps и отношения вариации Close 0.99967. Это демонстрация запоминания, не качества на новых данных. Более сложный loss не гарантировал лучшего запоминания. При принятом Open=предыдущий предсказанный Close фактические разрывы O/C также могут оставлять ненулевую ошибку формы.

Контролируемое сравнение

A — исходный loss; B — тот же угловой выход с ошибкой декодированных цен, формы и M3/M5/M10; C — обучаемая поправка к линейному log-price мосту между видимыми границами. Нулевая поправка равна интерполяции. Контекст512+512, LR1e-4, dropout25%, WD0.01. Каждая модель прошла4 полные эпохи по всем 517,095 допустимым скрытым целям. Это ограниченное дообучение сохранённого epoch12, не обучение с нуля. Диагностические веса не использовались.

Checkpoint каждого варианта выбран только по validation; победитель по этому критерию: C, эпоха 4. Оценка использует ранее исследованные данные. Критерий выбора — ценовая MSE относительно линейного моста, не визуальная резкость.
