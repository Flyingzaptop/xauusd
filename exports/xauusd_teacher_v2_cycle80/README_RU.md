# Лучший учитель v2, цикл80

Это teacher/reward model, выбранная по development utility; не последняя модель96цикла. Чекпоинт содержит веса и AdamW optimizer. Исходная архитектура/код/схемы включены. Cycle80 выбран до финального теста. Архитектура: 6 временных +6 межинструментальных Transformer блоков, hidden192,6heads,dropout0.25,patch10, 5,588,740 параметров.

## Быстрая проверка и подключение
Установить Python3.11+ и зависимости requirements.txt. Распаковать архив целиком. В каталоге выполнить `python load_teacher.py --self-test`. Тест загружает веса, проверяет SHA256 всех файлов и воспроизводит сохранённый ответ на синтетическом fixture. Это проверка подключения, не торгового качества.

Python: `from load_teacher import TeacherScorer; scorer=TeacherScorer('cuda'); scores=scorer.score(past,clock,future)`.
`past`: B×222×120×96; первые48каналов — asinh причинных признаков, следующие48 — маски валидности. Порядок инструментов и48признаков строго как в prepared.json (`symbols`, `names`). Абсолютные цены в past не подаются. Минуты отсутствия котировок нельзя просто склеивать: здесь календарные UTCминуты с явными масками/давностью данных. Вход в минуту t использует только закрытые свечи [t−120мин,t).
`clock`: B×8 — sin/cos времени суток для гармоник1,2,3, затем sin/cos дня недели; вычисление в prepare.py. Timestamp — UTC время открытия M1.
`future`: B×120×8 — будущие120минут XAUUSD от t доt+119. Четыре OHLCизменения, три накопленных H/L/C относительно entryOpen и маска наличия; точное построение в data.py. Нормирование будущего: sqrt(120*mean(предыдущих119изменений Close²)), сдвинутое так, чтобы масштаб был известен до входа; fallback1 при невалидном масштабе; clip±50.
Выход: B×2, столбцы LONG,SHORT, математические ожидания Beta распределений внутри(0,1). Это выученные оценки для RL, НЕ калиброванные вероятности прибыльной сделки. В обучении из этих Beta сэмплировались оценки; внутренний reward открытию=2*score−1, WAIT=0. Для deterministic scoring используется mean.

## Нормализатор
Отдельного обученного StandardScaler/mean/std файла НЕТ. Преобразования полностью задаются features.py и data.py: причинные rolling volatility/диапазоны, clip±50 при сохранении float16, затем asinh и finite-mask. Требуется именно этот код и порядок каналов. Нельзя подставить произвольные готовые индикаторы вместо них. Подробные48формул находятся в features.py. Максимальный lookback1440мин плюс120минконтекст и дополнительные лаги/давность; для точного воспроизведения использовать исходную подготовку, а не обрезать историю произвольно.

## Воспроизведение из исходных свечей
Оригинальные222файла указаны в drive_manifest.json с Drive IDs, размером; prepared.json и dataset_protocol.json сохраняют порядок/схему, audit/подготовка исходного запуска описаны в отчёте. prepare.py скачивает их и создаёт anchors.npy, gold_ohlcv.npy, clock.npy, features.f16, prepared.json в `/content/meta_reward`. Если путь другой — осознанно изменить R в prepare.py; data.Data принимает root аргументом. После подготовки: `python load_teacher.py --prepared-root /content/meta_reward --anchor-index N --device cuda`. cache=False в loader не требует держать75GBна GPU, но CPU RAM нужна для небольших вспомогательных массивов; считывается только нужное окно. Полный75GBдатасет и сырые свечи НЕ включены в этот архив.

## Ограничения применения
Учитель ОБЯЗАТЕЛЬНО видит будущее. Его можно использовать для разметки/награждения исторических действий ученика; подавать такой score live-трейдеру как доступную в реальном времени фичу — утечка будущего. Для live нужен отдельный past-only ученик, его веса в этом архиве не заявлены.

Обучение: train2016–2022, meta2023, dev28дней2024-03-04..2024-04-01, test84дня2025-01-06..2025-03-31. Позиция1унция, fixedexit120мин/UTCграница, стоимость0.25$/сделку условная. Тест относится к СВЕЖЕМУ ученику, обученному frozen teacher, не к прямой торговле учителем. Он заработал+231.67$за720сделок, всеLONG. Always-LONG на том же executor дал+255.63$за778сделок. Преимущество тайминга не доказано; одинseed. Полные метрики/графики включены. Дневная equity агрегирует прибыль закрытых сделок по дню входа и не является внутрисделочной mark-to-market просадкой.

## Версии
Исходное GPUобучение PyTorch2.11.0+cu130. Этот пакет и CPUfixture проверены отдельно с установленной локальной версией PyTorch (см package_validation.json). Требования не являются lockfile: окружение исходного Colab установило зависимости без полного pip freeze, поэтому точные версии всех библиотек неизвестны. Проверка fixture обязательна после смены окружения.
